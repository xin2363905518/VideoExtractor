# 视频提取器

提取网页中的视频到独立播放器中播放，不受原网站播放器限制。支持直链、HLS、DASH 及 blob 直播流。

## 功能

- 🔍 自动检测页面中所有视频播放器（包括动态加载的视频、open Shadow DOM 内的视频）
- 📤 一键提取视频到独立播放器播放
- 📺 支持网页全屏、浏览器全屏
- 🖱️ 网页全屏下可拖拽视频位置、滚轮缩放画面
- 🎚️ 自定义控制栏（播放/暂停、进度条、音量），仅在网页全屏时出现，5 秒无操作自动隐藏，鼠标移到底部时重新出现
- ⌨️ 浮层内支持 Esc / 空格 / 方向键 / M / F 快捷键
- 🎬 支持 blob: 直播流（浮层播放器，可调整大小，关闭后还原）
- 💾 开关状态按域名保存在 localStorage，刷新、关闭浏览器后仍保留，同域名多标签页共享，不同网站互不影响
- 🎯 按需开启，默认关闭

## 使用说明

1. 安装脚本后，点击 Tampermonkey 菜单中的 **“当前状态：关，点击开启”** 开启功能（默认关闭）
2. 页面中的视频右上角会出现一个 ▶ 图标
3. 点击图标：
   - 普通直链 / HLS / DASH → 在新标签页打开独立播放器
   - blob 直播流 → 在当前页面弹出浮层播放器，可拖拽调整大小、全屏、关闭后还原
4. 再次点击菜单中的 **“当前状态：开，点击关闭”** 即可关闭，图标消失，页面恢复原样

> 视频源还没加载出来时点击图标，右下角会提示“视频源尚未就绪”，按钮会保留，稍后重试即可，不需要刷新页面。
>
> 点击后按钮会短暂变灰（约 0.8 秒，防连点）随即恢复，**不会消失**；站点自动切下一集、换清晰度时按钮会自动跟随，不需要重新开关脚本。

## 支持格式

| 格式 | 说明 |
|------|------|
| 直链视频 | mp4 / webm / ogg 等 |
| HLS 流 | .m3u8（支持带 `?token=` 等查询参数） |
| DASH 流 | .mpd |
| blob 直播流 | blob: 地址（常见于直播网站） |

## 播放器操作

**新标签页播放器**：使用浏览器原生 `<video>` 控件（播放/暂停、进度、音量、全屏、画中画等）。

**浮层播放器**（blob 直播流）：

| 操作 | 说明 |
|------|------|
| ⤢ 网页全屏 | 进入网页全屏，出现自定义控制栏；再点一次退出 |
| ⛶ 浏览器全屏 | 等价于按 F |
| ✕ / `Esc` | 退出浮层（网页全屏中先退出网页全屏） |
| 控制栏 | 5 秒无操作自动隐藏，鼠标移到底部区域时重新出现 |
| 拖拽 / 滚轮 | 仅在网页全屏下：左键拖动画面、滚轮放大缩小 |

**快捷键**（浮层打开时生效，输入框内不拦截）：

| 按键 | 功能 |
|------|------|
| `Esc` | 退出网页全屏 / 关闭浮层 |
| `Space` | 播放 / 暂停 |
| `←` `→` | 后退 / 前进 5 秒 |
| `↑` `↓` | 音量 ±5% |
| `M` | 静音切换 |
| `F` | 浏览器全屏 |

## 注意事项

- 部分网站使用 MSE 动态推流（如 B站、YouTube），其视频源无法直接提取
- 跨域 HLS / DASH 流可能因 CORS 策略限制而无法播放
- 如果浏览器拦截弹窗，请允许该域名弹窗后重试
- blob 直播流提取后使用浮层播放器，关闭或退出网页全屏会自动还原视频原始状态
- 只支持 **open** Shadow DOM；`attachShadow({ mode: 'closed' })` 的组件无法访问
- 跨域 iframe 内的视频需要在该域名下单独开启脚本（开关状态按域名隔离）
- 浮层把原 `<video>` 元素整体搬入，关闭后放回原位；极少数依赖原 DOM 结构的播放器可能中断播放
- 按钮在浮层播放期间会自动隐藏，关闭浮层后重新出现
