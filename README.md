# 视频提取器

提取网页中的视频到独立播放器中播放，不受原网站播放器限制。支持直链、HLS、DASH 及 blob 直播流。

## 功能

- 🔍 自动检测页面中所有视频播放器（包括动态加载的视频）
- 📤 一键提取视频到独立播放器播放
- 📺 支持网页全屏、浏览器全屏
- 🖱️ 网页全屏下可拖拽视频位置、滚轮缩放画面
- 🎚️ 自定义控制栏（播放/暂停、进度条、音量），仅在网页全屏时出现，5 秒无操作自动隐藏，鼠标移到底部时重新出现
- 🎬 支持 blob: 直播流（浮层播放器，可调整大小，关闭后还原）
- 💾 开关状态按域名保存在 localStorage，刷新、关闭浏览器后仍保留，同域名多标签页共享，不同网站互不影响
- 🎯 按需开启，默认关闭

## 使用说明

1. 安装脚本后，点击 Tampermonkey 菜单中的 **“当前状态：关，点击开启”** 开启功能（默认关闭）
2. 页面中的视频右上角会出现一个 ▶ 图标
3. 点击图标：
   - 普通直链 / HLS / DASH → 在新标签页打开独立播放器
   - blob 直播流 → 在当前页面弹出浮层播放器，可拖拽调整大小、全屏、关闭后还原
4. 再次点击菜单中的 **“当前状态：开，点击关闭”** 即可关闭，图标消失，页面恢复原样

## 支持格式

| 格式 | 说明 |
|------|------|
| 直链视频 | mp4 / webm / ogg 等 |
| HLS 流 | .m3u8 |
| DASH 流 | .mpd |
| blob 直播流 | blob: 地址（常见于直播网站） |

## 播放器操作

**新标签页播放器**：使用浏览器原生 `<video>` 控件（播放/暂停、进度、音量、全屏、画中画等）。

**浮层播放器**（blob 直播流）：

- 网页全屏按钮 ⤢ → 进入网页全屏，此时出现自定义控制栏
- 控制栏 5 秒无操作自动向下隐藏，鼠标移到底部区域时重新出现
- 网页全屏下：鼠标左键拖拽画面可移动位置，滚轮可放大/缩小画面
- 关闭按钮 ✕ → 退出浮层，视频还原回原页面位置

## 注意事项

- 部分网站使用 MSE 动态推流（如 B站、YouTube），其视频源无法直接提取
- 跨域 HLS / DASH 流可能因 CORS 策略限制而无法播放
- 如果浏览器拦截弹窗，请允许该域名弹窗后重试
- blob 直播流提取后使用浮层播放器，关闭或退出网页全屏会自动还原视频原始状态
